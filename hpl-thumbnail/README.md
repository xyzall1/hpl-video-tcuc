# hpl-thumbnail

Claude Code skill for HPL / Telkom CorpU content thumbnails: competency cover, course cover, video and article thumbnails (16:9, 1920×1080) and audio thumbnails (1:1, 1080×1080). Titles come from the CMS workbook. Each competency gets one colour (kuning, tosca, biru, ungu, hijau, pink) and one ornament (13 shapes taken from the HPL thumbnail decks). Background brightness marks the level.

See `SKILL.md` for the rules and workflow. Rendering uses `npx hyperframes snapshot`.

Install: copy this folder to `~/.claude/skills/hpl-thumbnail`.

Font: Arial Bold is not included. On macOS the system copy is used automatically; elsewhere put it at `fonts/ArialBold.ttf`.
